# User components

Reusable buyer/storefront components.

```text
user/
├── catalog/
│   ├── product-card/   # Product summary card used in grids and lists
│   └── product-rail/   # Horizontally scrollable product collection
├── checkout/
│   └── checkout-steps/ # Checkout progress navigation
├── home/
│   └── hero-slider/    # Homepage promotional carousel
└── search/
    └── search-overlay/ # Storefront search dialog
```

Category and subcategory UI is intentionally not reorganized here while that
feature is being developed separately.
